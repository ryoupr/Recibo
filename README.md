# レシ簿 RECIBO

Android 向けのレシピ管理アプリ「レシ簿 RECIBO」の配布用リポジトリです。インストール用の APK とリリースノートを [Releases](https://github.com/ryoupr/Recibo/releases) で公開しています。

> このリポジトリにアプリのソースコードはありません。各リリースに自動で付く「Source code (zip / tar.gz)」は、このリポジトリの中身（この README など）で、アプリのソースではありません。

## 主な機能

- レシピの作成・編集・検索、ジャンル別のフィルターと並び替え
- 献立の作成と、選んだレシピからの買い物リストの自動作成
- 調理タイマー（手順の中の時間表記をタップして起動。複数同時に使える）
- URL からの取り込み（AI 解析。接続先と API キーは利用者が設定する）
- QR コードでのレシピの受け渡し
- Google ドライブとの同期、バックアップとリストア
- ゴミ箱（削除したレシピを一定期間保管し、復元できる）
- ライト／ダークテーマ、アクセシビリティ設定

## 動作環境

Android 7.0（API レベル 24）以上

## インストール

1. [最新のリリース](https://github.com/ryoupr/Recibo/releases/latest) から `Recibo-vX.Y.Z.apk` をダウンロードします。
2. ダウンロードした APK を開きます。初めてのときは、提供元不明のアプリのインストールを許可する必要があります。
   - Android 8.0 以降: APK を開いたアプリ（ブラウザやファイルアプリ）に対して「不明なアプリのインストール」を許可します。
   - Android 7.1.1 以下: 「設定 > セキュリティ」の「提供元不明のアプリ」を有効にします。
3. 画面の案内に従ってインストールします。

新しい版が出たら、同じ手順で上からインストールします。データはそのまま引き継がれます。

## 正式版とアルファ版

| 種類 | Releases での表示 | 署名 |
|---|---|---|
| 正式版 | `Latest` が付いた通常のリリース | 本番の鍵 |
| アルファ版（試験版） | `Pre-release`（`vX.Y.Z-alpha`） | テスト用の鍵 |

**アルファ版の注意**: アルファ版は正式版と同じアプリとしてインストールされますが、署名が異なります。そのため、正式版の上からアルファ版を入れることはできず、その逆もできません。切り替えるにはアンインストールが必要で、アプリ内のデータは消えます。切り替える前に、アプリの「バックアップ」機能でデータを書き出してください。

## プライバシー

広告や追跡の仕組みは入っていません。アプリが外部のサーバーと通信するのは、URL 取り込み（指定したサイトの取得と AI 解析）と Google ドライブ同期を使ったときだけです。詳しくは[プライバシーポリシー](PRIVACY.md)を参照してください。
